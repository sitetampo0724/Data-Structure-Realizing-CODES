## 1.vector can not be a container for realizing queue

as it is not quite efficient in inserting elements.

## 2.deque is a default container for both stack and queue
for its excellence in efficiency

- **deque** :A deque (pronounced "deck") is a sequence container that 
supports constant-time insertion and removal at both ends, while still 
providing random access to elements. The name comes from "Double-Ended Queue".
Unlike vector which stores elements in a single contiguous memory block, deque 
uses a segmented memory architecture that allows efficient growth 
at both ends.
